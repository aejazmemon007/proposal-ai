# ProposalAI — AI-Powered Proposal Generator

**ProposalAI** is a modern, high-converting proposal generation platform for freelancers, agencies, and studios. Generate custom scopes of work, intelligent pricing estimates, interactive client proposals, and track views and approvals in real-time.

---

## ✨ Features

- ⚡ **AI Brief Analysis**: Turns unstructured client briefs into detailed scopes of work, deliverables, and timelines.
- 💰 **Smart Pricing Engine**: Suggests fixed, milestone, hourly, or retainer pricing based on project scope and experience.
- 🎨 **Theme & Tone Customization**: Switch between Professional, Friendly, Premium, Minimal, and Persuasive proposal styles with dark mode support.
- 🔗 **Zero-Config Live Sharing**: Send shareable public links (`/p/:token`) that work across any client browser or mobile phone without a database setup.
- ✍️ **Client Interactive Approvals**: Clients can accept proposals with agreement checks or submit revision feedback directly on the public page.
- 📄 **Print & PDF Export**: Optimized `@media print` layout for exporting proposals to PDF.
- 📊 **Analytics & Client CRM**: Track pipeline value, acceptance rates, client history, and proposal statuses.

## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Local Development Server
```bash
npm run dev
```
Preview at **`http://localhost:8443`**

### 3. Build for Production
```bash
npm run build
```

### 4. Preview Production Build
```bash
npm run preview
```
